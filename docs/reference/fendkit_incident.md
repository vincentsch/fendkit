# fendkit incident

Record awareness, reporting deadlines and filing drafts

The maker decides when they became aware. Fendkit prepares drafts locally.
A person submits in ENISA's Single Reporting Platform; submitted only records that filing.

## Inherited flags

```text
      --config string   Path to the config file
      --dir string      Project root (default ".")
      --dry-run         Preview changes without performing them
      --json            Output stable JSON instead of the human view
      --no-prompt       Never block on an interactive prompt
      --quiet           Suppress non-essential output
```

## Usage

```
fendkit incident
```

## Examples

```
fendkit incident list
```
