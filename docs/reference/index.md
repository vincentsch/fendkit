# fendkit command reference

Prepare your Cyber Resilience Act evidence

## Commands

- [fendkit check](fendkit_check.md) - Show evidence status and the next actions
- [fendkit demo](fendkit_demo.md) - Try Fendkit on the bundled example plugin
- [fendkit docs](fendkit_docs.md) - Create missing draft documents and refresh the index
- [fendkit doctor](fendkit_doctor.md) - Check project setup and advisory connections
- [fendkit incident](fendkit_incident.md) - Record awareness, reporting deadlines and filing drafts
- [fendkit incident fix-available](fendkit_incident_fix-available.md) - Record when a fix or mitigation became available
- [fendkit incident list](fendkit_incident_list.md) - List incidents with deadlines and submission status
- [fendkit incident new](fendkit_incident_new.md) - Record an incident and create filing drafts
- [fendkit incident show](fendkit_incident_show.md) - Show current deadlines and paths to filing texts
- [fendkit incident submitted](fendkit_incident_submitted.md) - Record a person's filing in ENISA's platform
- [fendkit init](fendkit_init.md) - Record your decisions and prepare draft CRA documents
- [fendkit scan](fendkit_scan.md) - Find dependencies and look up known vulnerabilities
- [fendkit triage](fendkit_triage.md) - Record a decision and export product-specific VEX

## Global flags

- `--config` Path to the config file
- `--dir` Project root
- `--dry-run` Preview changes without performing them
- `--json` Output stable JSON instead of the human view
- `--no-prompt` Never block on an interactive prompt
- `--quiet` Suppress non-essential output
