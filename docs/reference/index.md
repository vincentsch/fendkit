# conformline command reference

Prepare your Cyber Resilience Act evidence

## Commands

- [conformline check](conformline_check.md) - Show evidence status and the next actions
- [conformline demo](conformline_demo.md) - Try Conformline on the bundled example plugin
- [conformline docs](conformline_docs.md) - Create missing draft documents and refresh the index
- [conformline doctor](conformline_doctor.md) - Check project setup and advisory connections
- [conformline incident](conformline_incident.md) - Record awareness, reporting deadlines and filing drafts
- [conformline incident fix-available](conformline_incident_fix-available.md) - Record when a fix or mitigation became available
- [conformline incident list](conformline_incident_list.md) - List incidents with deadlines and submission status
- [conformline incident new](conformline_incident_new.md) - Record an incident and create filing drafts
- [conformline incident show](conformline_incident_show.md) - Show current deadlines and paths to filing texts
- [conformline incident submitted](conformline_incident_submitted.md) - Record a person's filing in ENISA's platform
- [conformline init](conformline_init.md) - Record your decisions and prepare draft CRA documents
- [conformline scan](conformline_scan.md) - Find dependencies and look up known vulnerabilities
- [conformline triage](conformline_triage.md) - Record a decision and export product-specific VEX

## Global flags

- `--config` Path to the config file
- `--dir` Project root
- `--dry-run` Preview changes without performing them
- `--json` Output stable JSON instead of the human view
- `--no-prompt` Never block on an interactive prompt
- `--quiet` Suppress non-essential output
