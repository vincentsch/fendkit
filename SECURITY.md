# Report a security issue

This policy covers vulnerabilities in Conformline itself.
Please email [vschmalbach@vschmalbach.com](mailto:vschmalbach@vschmalbach.com)
privately, or use GitHub private vulnerability reporting when available.
Include the Conformline version, affected command and steps to reproduce.
Remove credentials and private project data before sharing output.
Please wait to discuss the issue publicly until a fix is available.

Conformline is pre-1.0. Security fixes target the latest release.
Its generated vulnerability disclosure documents are drafts for your product
and need your own contact details and review.
